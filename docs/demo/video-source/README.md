# How the 4-minute walkthrough was made

The finished videos are attached to the GitHub Release (not committed): `probably-a-tragedy-walkthrough.mp4` (1080p, 4:09, ~48 MB) and
`probably-a-tragedy-walkthrough-720p.mp4` (~23 MB, for messaging).

* **Real animation, no screen recording.** `rec/rec.swift` (`swiftc -O rec.swift -o rec`) renders a page in an offscreen `WKWebView`
  (window at -5000,-5000) with WebKit's occlusion detection switched off so animations run at 60 fps, grabs frames with `cacheDisplay`,
  and writes H.264 itself. `director_*.js` drive the game like a player (fake cursor included). See `rec/README.md`.
* **Live graph visuals** (`viz/`): `live_graph.html` fetches each graph's real structure from the LangGraph server and runs it for real,
  animating nodes, the Send fan-out, reducers, interrupts and checkpoints. `trace.html` is a readable animated trace built from real
  LangSmith run data (`make_trace_data.py`, needs `LANGSMITH_API_KEY` in the environment). `overview.html` shows all nine graphs.
* **Studio footage** was recorded through a local HTTPS proxy (`rec/tlsproxy.py 2028 2027`), because WebKit blocks https to http://127.0.0.1.
* **The real LangSmith frames** (`shots/c0*.png`, scene K2) are screenshots of Studio's Trace tab taken in a signed-in Chrome and cropped
  to remove account details. LangSmith itself is not recorded live.
* **Narration**: OpenAI `gpt-4o-mini-tts`, voice `marin` (`narration/tts_config.json`), generated by `narration/tts.py` from `script.json`
  (reads `OPENAI_API_KEY` from the repo's `.env`; about 10 cents). Change the voice, then `python3 narration/tts.py all`.
* **Assembly**: `build_video2.py manifest_v2_final.json out.mp4 --small` drives FilmCraft through its control server (the footage in
  `raw/` and recordings in `viz_out/` are not included: 330 MB; re-record with `rec` and the directors).
